### Qualitative evidence

- Learners value Kubernetes, deploying the app, autonomy, reflection questions, and the lab format.
- Two explicitly mention excessive writing, including producing Markdown lab reports; one asks directly for less writing.
- One requests automated repository evaluation for faster feedback.
- Two select “too open-ended”; this supports clearer entry points and checks while retaining independent reasoning.
- One asks for a little more time. The pace split does not support accelerating everyone uniformly.
