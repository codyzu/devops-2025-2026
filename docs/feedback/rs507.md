### Qualitative evidence

- CI and pipeline work recur as valuable activities. Learners appreciate immediate visible results, an existing application they can modify, and concentrating on tools rather than developing an app from scratch.
- Several comments request more material, greater depth, or more independent exploration. Some describe early work as familiar basics or finishing quickly.
- Instructor responsiveness and individual correction are valued. One comment describes waiting too long for correction while still supporting individual review.
- One asks for clearer notice that debugging supplied code can be part of the exercise.
- Requested next topics include Kubernetes, testing/quality automation, security, cloud, observability, and infrastructure as code. Interest does not establish a commitment to add every topic.

## 2025–2026 implications and action status

Retain a guided starting point while making meaningful extensions available earlier. Nine respondents found the pace slow, but two found it fast; uniformly accelerating would miss that difference.

Self-reported confidence is not an observed competency test. In particular, strong Git confidence does not establish that everyone can independently explain CI or debug container work.

Most-valued selections: CI (12), Git/workflows (10), Docker/containerization (9), understanding why tools are used (7), Compose (5), and debugging/breaking/fixing (4).

Next-course interests: Kubernetes (11), cloud platforms (10), infrastructure as code (9), monitoring/observability (7), testing/quality automation (6), and security (6). These questions allow multiple selections, so totals exceed 20. One next-topic response contained no substantive topic and is excluded from topic counts. Interest does not add a new course requirement.

### Qualitative evidence

- One respondent explicitly wants to retain Lab 30's extension lanes. Another values the CI workflow, and another the course structure and timing.
- One improvement comment asks for more independent discovery; another proposes a reference of important commands followed by exercises where learners choose which commands to use. The latter also selected slightly too guided.
- One respondent explicitly values the grading system. This positive comment coexists with the neutral and negative fairness ratings; it does not explain them away.
- Many improvement fields are blank or contain no requested change. No substantive free-text explanation identifies the cause of the lower fairness ratings, and the sheet does not identify which extension was too difficult. Do not assign either issue to a particular lane, grading policy, or wait time without further evidence.
